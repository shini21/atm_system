# Apex Bank Touchscreen ATM - Frontend

This is the React Single Page Application (SPA) touchscreen interface for the Modern ATM Banking System.

## Technology Stack
- **Framework**: React 18 + Vite 6 + TypeScript
- **Styling**: Tailwind CSS (Dark Fintech theme)
- **Animation**: Motion for React (`motion/react`)
- **Iconography**: Lucide React
- **HTTP Client**: Axios with server-side session credentials

## Development Commands

```bash
# Navigate to frontend
cd frontend

# Install dependencies
npm install

# Start development server with live API proxy
npm run dev
# Running at http://localhost:5173

# Typecheck and build for production
npm run build
```
